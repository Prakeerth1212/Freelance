FreelanceHub

Full-Stack Freelance Business Management Application — Complete Project Summary

📋 Overview

FreelanceHub is a full-stack freelance business management application built with React + TypeScript + Vite + MUI (frontend) and Spring Boot 3 + MySQL (backend). Originally a basic CRUD app with outdated UI and plain-text passwords, it was transformed into a modern, production-ready application through a comprehensive overhaul covering security, UI/UX, currency support, and developer tooling.

🛠 DevOps & Deployment

  • Build pipeline: node build.js → TypeScript compile + Vite production build
  • Static serving: Frontend dist copied to backend/src/main/resources/static/ — single JAR serves both API and UI
  • Deployment: Configured for Railway & Render — cd backend && mvn clean package -DskipTests
  • Auto-deploy: Push to master triggers automatic redeployment
